### Hi 👋

Windows sysadmin tools – mostly PowerShell and C#, built for everyday work in Active Directory environments.
*Werkzeuge für Windows-Admins – überwiegend PowerShell und C#, aus dem Alltag in Active-Directory-Umgebungen.*

#### ⭐ Featured

**[DHCP WMI Viewer](https://github.com/thhering1969/dhcp-wmiviewer)** – portable GUI for Windows DHCP servers:
scopes, reservations and leases, a confirmation before every change, automatic failover replication
(*Replicate Scope*) and an audit trail on both partners. English/German.
[Download](https://github.com/thhering1969/dhcp-wmiviewer/releases/latest)

#### More

- [AD-Powershell-tool](https://github.com/thhering1969/AD-Powershell-tool) – PowerShell GUI for common Active Directory tasks
- [Export-ExchangeURLs.ps1](https://github.com/thhering1969/Export-ExchangeURLs.ps1) – export Exchange URLs (Exchange 2007 compatible)
- [LCD-Smartie](https://github.com/thhering1969/LCD-Smartie) / [arduinoHwInfo](https://github.com/thhering1969/arduinoHwInfo) – Arduino-driven LCD info screen and hardware monitor
